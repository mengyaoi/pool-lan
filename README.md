# 双人台球 · 局域网对战

写实俯视 2D 台球（对标天天台球画风）：木框库边、绿绒台面、带号码高光球、虚线瞄准辅助线 + 幽灵球、力度条、加塞杆法盘。
**零 npm 依赖**，WebSocket 服务端是手写的。

---

## 怎么玩

### 方式一：双击（最简单）

双击 `start.bat` → 自动起服务端并打开浏览器。

会弹一个黑窗口，上面印着：

```
  本机：      http://localhost:8080
  局域网：    http://192.168.1.23:8080
```

**两台电脑都连同一个 WiFi**，各开一个浏览器输那个「局域网」地址，就能对打了。
只来一台电脑？开两个浏览器窗口也可以，一人一个窗口。

> 首次运行 Windows 会弹防火墙提示，点**允许访问**，否则另一台机器连不上。

### 方式二：命令行

```bash
node server.js          # 换端口：PORT=9000 node server.js
```

### 方式三：不开服务端，同屏双人

直接双击 `public/index.html`，或在地址后加 `?local=1` —— 自动降级为本地同屏，两人轮流用同一台电脑。

## 操作

| 动作 | 操作 |
|---|---|
| 瞄准 | 鼠标在台面上移动，瞄准线跟随 |
| 加力 | **按住左键拖动**（任意方向），拖得越远力越大，底栏力度条实时显示 |
| 出杆 | 松开左键 |
| 取消拉杆 | 按 `Esc`，或拉得太短（< 5%）松手等于取消 |
| 杆法 | 左下角小白球盘里拖击球点：上=高杆（跟进）、下=低杆（回旋）、左右=加塞 |
| **自由球摆球** | 白球周围出现金色箭头时，**按住白球**拖到目标位置松开（绿环可放 / 红环不可放） |
| 静音 | 底栏「音效」 |

> 击球点拖到红圈外会**滑杆**（miscue），球打不出去。红圈内 0.72 倍半径是安全区。

## 规则（经典八球）

15 颗球：**实心 1~7 / 花色 9~15 / 黑 8**。开局摆三角，白球在开球线后。

### 开局
- 开球表**开放（open table）**，这一杆进什么球都不定花色。
- 开球后第一杆**合法进球**才定花色：先进实心归实心，先进花色归花色；进两颗不同组则仍开放。
- 定组后只能打自己那组，最后打黑 8。

### 犯规 → 对手获得「自由球」
经典八球里犯规的代价不是简单换手，而是**对手拿到全台自由球（ball-in-hand）**——可以把白球放到台面任意合法位置再出杆。

代码里判定的三类犯规：

| 犯规 | 判定依据 |
|---|---|
| **空杆** | 白球什么都没碰到（`firstContact === null`） |
| **先碰非法球** | 开放表先碰黑 8 / 已定组先碰对方那组 / 清完己方球后先碰的不是黑 8 |
| **白球落袋** | 白球进袋 |

犯规后：换手 **且** `match.ballInHand = 对手`，状态栏提示「自由球 · 玩家 X 抓住白球拖到任意位置」。

摆球交互：
- 白球周围出现**金色脉冲环 + 四向箭头**，表示这颗球可以抓
- 按住白球拖动 → 预览幽灵球，**绿环 = 可放**，**红环 + 禁止符 = 不可放**（压球、压袋口、出台）
- 松开：合法即落位（自由球消耗掉，球杆出现）；非法则弹提示，自由球保留
- 不想挪位置就**直接在台面按住拖动出杆**，等于接受当前白球位置

### 其他
- **合法进球可以继续打**，没进球换手（走位失误不罚自由球）。
- 提前打进黑 8 判负；清完己方花色后打进黑 8 获胜。
- 母球落袋时物理层会先复位到开球点，但那只是临时占位——最终位置由拿到自由球的一方决定。

## 视觉与音效

### 进球粒子
球落袋时在袋口炸开三层效果：**扩散冲击波环 → 球缩入袋口 → 22 颗带重力与拖尾的粒子**（0.9s）。粒子颜色取自进球本身，深色球（黑 8 / 紫 / 蓝）会自动向白色提亮，否则在绿台面上看不清。粒子轨迹由 `球号 + 袋口坐标` 算出的确定性种子生成，本地与联机两端不需要同步粒子状态，只同步一个 seed。

### 胜利彩带
分出胜负后撒 170 片彩色纸片（平局 55 片），带旋转、左右摆动、翻转压扁和渐隐，持续 5.2s。彩带画在**独立的全屏 canvas 层**（`z-index:50`、`pointer-events:none`），这样能飘在胜利面板的半透明遮罩之上；重开一局会立即清空。

### 分层音效
WebAudio 程序合成，零音频文件。总线结构：

```
[table] 球撞球 / 撞库 / 落袋 ─┐
[cue]   出杆 / 滑杆          ─┼→ [master] → 输出
[ui]    换手 / 得分 / 胜负   ─┘
```

每条总线独立增益，默认 `table 0.9 / cue 1.0 / ui 0.8 / master 0.85`。每个事件自身也叠 2~4 层（高频瞬态 + 主体共鸣 + 低频/尾音）。运行时可调平衡：

```js
__pool.mix({ table: 0.55, ui: 1.15, master: 0.9 })
```

联机时**赢家播 `win()`、输家播 `lose()`、平局播 `draw()`** —— 原来是所有人统一播胜利音效，输的一方也听号角，已修。胜负音效统一由 `showOverlay` 触发一次，传输层不再重复推送。

### 调试预览
控制台 `__pool` 暴露了几个只读预览口，方便调特效：

```js
__pool.fx(8, 0, 0.6)        // 在指定世界坐标预览一次落袋粒子 + 音效
__pool.celebrate('win')     // 撒彩带；'draw' 撒少量，null 清空
__pool.sfx('ballHit', 3)    // 单独试听某一层
__pool.mix({ ui: 0.5 })     // 调混音，返回当前各层增益
__pool.layers               // 读当前增益
__pool.clearFx()            // 清掉所有预览特效
```

## 物理实现

不是「碰一下弹开」的假物理，是真刚体：

- 球心速度 `v` + 三轴角速度 `ω`，区分**滑动**与**滚动态**
- 滑动摩擦 `a = −μs·g·û`，角加速度 `α = (5μs·g/2R)(ẑ×û)`，滑移归零时刻严格等于 `2|u₀|/(7μs·g)`
- 滚动约束 `ω = (ẑ×v)/R`，滚动摩擦 `μr = 0.016`
- 球-球：等质量、恢复系数 0.95，切向摩擦产生 **throw**（塞会拐）
- 库边：法向恢复 0.75，切向摩擦 0.2，**加塞会改变反弹角**
- 袋口判定优先于库边，库边在袋口处留缺口

台面 2.54m × 1.27m，球半径 28.575mm，质量 170g，全部 SI 单位。参数在 `public/js/physics.js` 顶部的 `CFG` 里，想调手感直接改。

## 联机架构

```
浏览器 A ──┐                    ┌── 物理模拟 240Hz（服务端权威）
           ├── WebSocket ───────┤
浏览器 B ──┘                    └── 快照 20Hz 广播 → 客户端插值 90ms
```

- 服务端跑物理，客户端只做**插值和渲染**，两端永远不会不同步
- 客户端按 90ms 缓冲插值相邻快照，位置跳变 > 0.15m 直接吸附（换局/复位不会拉出一条横穿台面的线）
- 出杆校验：不是你的回合、不在瞄准阶段，服务端直接丢弃
- 掉线：对端立刻收到提示；房间空了本局作废，等人齐自动重开

## 常见问题

**对方打不开我的地址？**
1. 确认两台机器在同一个 WiFi/网段
2. Windows 防火墙放行：控制面板 → Windows Defender 防火墙 → 允许应用通过 → 勾上 Node.js 的「专用」和「公用」
3. 路由器开了「AP 隔离」会导致设备互不可见，关掉它

**端口被占用？** `PORT=9000 node server.js`，端口换成 9000。

**对手直接关掉浏览器，房间显示「已满」？**
服务端每 15 秒发一次 WebSocket ping，45 秒收不到任何回应就把连接踢掉、释放座位。
所以关页/断网后最多等 45 秒就能重新进房，不用重启服务端。
（想调短：`PING_EVERY=5000 DEAD_AFTER=15000 node server.js`）

**球太小看不清？** 窗口拉大，或按 F11 全屏，台面会自动撑满。
